# Tangible Bits｜打破螢幕與實體世界的介面革命

以 Hiroshi Ishii 的 Tangible Bits（TUI）概念為主題的互動式網頁簡報，共 13 頁。

## 線上檢視

啟用 GitHub Pages 後，網址會是：

```
https://<你的帳號>.github.io/<repo 名稱>/
```

## 操作方式

- 方向鍵、空白鍵或滾輪換頁；右側圓點可直接跳頁
- 靈感頁：撥動算盤
- GUI vs. TUI：切換比較焦點
- 互動表面、metaDESK：點選查看說明
- 背景環境媒體：點選項目，把它拉進注意力中心
- ambientROOM：調整點擊率，改變雨量與漣漪，可開啟雨聲
- transBOARD：在白板上畫圖，再把 hyperCARD 拖到白板上
- 數位影子：拖曳手電筒，觀察數據影子的變化

## 檔案結構

```
index.html          簡報本體（HTML、CSS、JavaScript）
assets/images/      插圖
.nojekyll           讓 GitHub Pages 直接提供靜態檔案
```
